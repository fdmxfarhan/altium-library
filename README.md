# 🛠️ Altium Designer Component Library

**A comprehensive collection of high-quality Altium Designer components and symbols for your electronics projects.**

---

## 🌟 Featured Components

| Component Category       | Specific Components                          |
|--------------------------|---------------------------------------------|
| **Microcontrollers**     | Arduino Nano, Black Pill STM32, Blue Pill STM32F103, ESP8266 |
| **Connectors**           | Header (Male/Female), Molex, JST, XT60, Type-C |
| **Passive Components**   | RES, RES SMD, CAP, CRYSTAL, Inductor, Potentiometer |
| **Semiconductors**       | Diode, LED, L6203-L298                       |
| **Modules**              | HC05 Bluetooth, OLED Display                 |
| **Electromechanical**    | Relay, Pushbutton, Rocker Switch             |
